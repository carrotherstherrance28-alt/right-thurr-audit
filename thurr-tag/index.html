FAQ

Good questions before a sample.

Does it track my bag?

No. Thurr Tag is not GPS, AirTag, or active tracking. It is a premium NFC tap-to-connect tag.

What happens when someone taps it?

It opens a Thurr URL that can show a profile, vCard, booking link, client message, or return contact page.

Will every phone read it?

Modern iPhones and many Android phones read NFC. The box also includes a QR fallback for clean handoffs.

When will it ship?

No ship date is promised yet. Production starts only after the sample passes and the validation gate is real.
